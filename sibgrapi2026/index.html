Trainer tips

Set up your team

No install needed: press RUN ONLINE on a notebook to open it in Google Colab. To run locally instead (CPU, a few minutes per LAB), use Python 3.10 or newer:

python -m venv .venv
source .venv/bin/activate
pip install torch numpy scipy matplotlib \
            scikit-image plotly jupyter
jupyter lab

Battle order

The slides announce each LAB when it is time to switch to the notebook, and each LAB ends with the slide to go back to. Run LAB 0 first, and keep FAST_MODE = True to follow along live.

Evolution line

Block 1 goes from SDFs to neural UDFs, gradients, projection and Marching Cubes. Block 2 covers points, images, alternative representations and meshing.
